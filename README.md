## About

ALU - Arithmetic and Logic Unit

Developed for an academic project, it was implemented in C# by developers Igor Palhares and Paulo Rocha.

The main objective of this project is to develop an object-oriented program to better understand the functioning of the Arithmetic and Logic Unit (ALU) within the Central Processing Unit (CPU). 
The program performs arithmetic operations (such as addition, subtraction, multiplication, and division) and logical operations (such as AND, OR, and NOT) on numbers converted between decimal, octal, hexadecimal, and binary bases. 
The ALU is implemented in four variants, with capacities of 1 bit, 8 bits, 16 bits, and 32 bits.
